## 🔍 Troubleshooting

**P: Modelo ainda não retorna "ganho"**
- Verifique stdout do `train_new_models.py` — veja as classes e probabilidades do teste rápido.
- Se mostrar 100% para "gasto", pode haver um problema no tratamento dos dados ou no LogisticRegression.

**P: Erro ao carregar dataset**
- Verifique caminho: `..\..\docs\classification.json` (relativo ao script).
- Valide JSON: `python -m json.tool C:\Users\Suyane Carvalho\SoFiA\docs\classification.json`

**P: Modelos não foram salvos**
- Verifique permissões de escrita em `train_model/`.
- Confirme que `joblib` está instalado: `pip install joblib`
